# **App Name**: Tournament Tracker

## Core Features:

- Team Creation: Create teams and add them to groups.
- Page Navigation: Create a new page with a button on the homepage.
- Match Scheduler: Create match pairings for all teams within a group, ensuring each team plays against every other team.
- Score Tracker: Record match outcomes (win, draw, loss) using dropdown menus, and automatically calculate points based on the outcome (3 for win, 1 for draw, 0 for loss).
- Point Display: Display the cumulative score of each team after each match.
- Player Stats: For each team, display players with their positions. Allow users to input goals scored per player. Use dropdown menus to display all options.

## Style Guidelines:

- Primary color: A vibrant green (#6BBF59) to convey growth, success, and energy, aligning with the spirit of competition.
- Background color: A light, desaturated green (#E9F5E7), creating a calm and unobtrusive backdrop for the competition data.
- Accent color: An analogous yellow (#BFA749), providing a warm, sunny highlight for key interactive elements.
- Headline font: 'Poppins' (sans-serif) for headings, to provide a modern, sporty, and highly readable appearance.
- Body font: 'PT Sans' (sans-serif) for body text, to complement the above while ensuring readability in longer-form content.
- Use flat, simple icons representing teams, matches, and players. Icons should be in the accent color (#BFA749) or primary color (#6BBF59) to maintain consistency.
- Use a grid-based layout to organize the different groups, teams, and matches. Ensure a responsive design that adapts to different screen sizes.
